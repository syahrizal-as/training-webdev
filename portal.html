Agenda Pelaksanaan Pelatihan Bersama Fasilitator (3 Hari)

Berdasarkan silabus dan materi aktual pelatihan, berikut pembagian materi 3 hari bersama fasilitator (Syahrizal As.):

  1. Hari 1 · Bedah Detail Slide Presentasi & Panduan Unit Kompetensi (Modul 01–03). Fasilitator menjelaskan secara detail dua materi acuan utama langsung di portal: slide presentasi interaktif (Slide Presentasi 8 Slide) mengenai alur client-server, peran developer, tools pengembangan (PHP 8.2+, Composer, VS Code, Git), inisialisasi Laravel 13, serta panduan teknis komprehensif (Panduan Teknis 12 Bab) yang mengulas 22 unit kompetensi SKKNI industri (Database SQL, MVC, Testing & UAT, Security OWASP, Logging, dan Standar Mutu). Dilanjutkan pengerjaan Pre-Test dan slicing form Bootstrap.
  2. Hari 2 · Integrasi Laravel 13, Template SB Admin 2 & CRUD Master (Modul 04–06 / hari-2.md). Memahami arsitektur Model-View-Controller, routing web, pembuatan skema database dengan migration, query SQL & Eloquent ORM, serta operasi CRUD master data pelanggan lengkap dengan validasi form server-side dan proteksi CSRF berdasarkan panduan hari-2.md.
  3. Hari 3 · Transaksi Data Berelasi & RESTful API Sanctum (Modul 07–08 / hari-3.md). Membangun relasi One-to-Many antartabel, menjaga konsistensi transaksi menggunakan DB Transaction & rollback, serta membangun endpoint RESTful API terproteksi Bearer Token menggunakan Laravel Sanctum via Postman sesuai panduan hari-3.md.
  4. Sesi Pengayaan & Penjaminan Mutu · Belajar Mandiri (Modul 09–10). Memverifikasi sistem melalui pengujian User Acceptance Testing (8 test cases UAT), pencatatan bug defect, automated testing PHPUnit, audit keamanan (OWASP), dan penyusunan checklist rilis staging produksi.

Catatan: Pembagian modul portal memecah materi menjadi langkah terukur untuk belajar mandiri, tanpa mengubah durasi atau agenda resmi kelas fasilitator.

STUDI KASUS PORTOFOLIO NYATA

Customer Workspace

Bangun sistem pengelolaan data pelanggan berbasis Laravel 13 dan Blade. Aplikasi mencakup CRUD data master, validasi server-side, relasi data pesanan (One-to-Many), transaksi atomik, dan endpoint RESTful API terproteksi token.
