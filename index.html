Tampilan & Interaksi Pengguna

Front End Developer

Front End Developer adalah orang yang bertanggung jawab membangun seluruh elemen visual yang dilihat, dibaca, dan disentuh langsung oleh pengguna di layar peramban (browser) mereka.

💡 Analogi Sederhana: Ibarat desainer interior dan penata etalase toko. Mereka memastikan toko tampak indah, tombol pintu pas saat disentuh, susunan produk rapi, serta pembeli merasa nyaman dan tidak bingung saat berbelanja.
Alur Kerja Harian:
  • Menerima rancangan visual desain (Figma/Adobe XD).
  • Menyusun struktur semantik menggunakan HTML5.
  • Menghias tata letak responsif menggunakan CSS/Bootstrap.
  • Menambahkan efek animasi & logika form interaktif via JavaScript.
HTML5 Semantik CSS3 / Bootstrap JavaScript DOM Responsive UI
Logika Server & Basis Data

Back End Developer

Back End Developer mengelola mesin di balik layar yang tidak kasat mata: pemrosesan logika bisnis, validasi keamanan, manajemen database, autentikasi login pengguna, dan pengiriman data API.

💡 Analogi Sederhana: Ibarat dapur restoran dan brankas penyimpanan. Saat pelanggan memesan di etalase depan, koki di dapur yang memasak pesanan, memeriksa stok bahan di gudang pendingin, dan memastikan keamanan transaksi.
Alur Kerja Harian:
  • Menerima request HTTP masuk dari browser/klien.
  • Memvalidasi keaslian data dan memeriksa izin akses.
  • Melakukan kalkulasi data dan kueri SQL ke database MySQL.
  • Mengamankan sistem dari serangan siber (SQL Injection, CSRF).
PHP 8.2+ / Laravel MySQL Database RESTful API Keamanan Server
Pengembang Serba Bisa (End-to-End)

Full Stack Developer

Full Stack Developer menguasai seluruh lapisan teknologi (end-to-end). Mampu merancang antarmuka pengguna sekaligus membangun arsitektur server, basis data, dan jalur integrasi sistem.

💡 Analogi Sederhana: Ibarat arsitek bangunan yang juga menguasai teknik sipil. Ia paham bagaimana merancang fasad rumah yang estetik, sekaligus paham instalasi kelistrikan, saluran pipa air, dan kekuatan fondasi beton di bawah tanah.
Alur Kerja Harian:
  • Menganalisis kebutuhan bisnis klien dari hulu ke hilir.
  • Merancang skema relasi basis data (tabel master & transaksi).
  • Menulis controller, model Eloquent, dan endpoint API backend.
  • Menghubungkan view antarmuka frontend secara mulus tanpa celah.
Full Stack Laravel Blade & JS UI SQL Architecture Git & Deployment

Panduan Setup Proyek Laravel 13

Langkah demi langkah inisiasi proyek baru dan koneksi basis data.

Instalasi & Persiapan

Terminal Command
Terminal VS Code 
composer create-project laravel/laravel:^13.0 app-name
cd app-name
php artisan serve
  • Buka integrated terminal di dalam Visual Studio Code.
  • Pastikan versi PHP (php -v) dan Composer (composer -v) sudah aktif.
  • Jalankan perintah instalasi proyek Laravel di atas.
  • Buka peramban (browser) dan akses http://localhost:8000.

Konfigurasi Basis Data

MySQL Setup
  • Aktifkan modul Apache dan MySQL pada Control Panel XAMPP.
  • Buka phpMyAdmin di browser (http://localhost/phpmyadmin) lalu buat database baru.
  • Buka file konfigurasi environment .env pada root folder project Laravel di VS Code.
  • Sesuaikan parameter DB_DATABASE=nama_database_anda.
  • Jalankan migrasi skema awal di terminal: php artisan migrate.
Buka Dokumentasi Resmi Laravel 13.x
